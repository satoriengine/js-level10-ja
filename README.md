# JavaScriptレベル10

JavaScriptレベル1〜9では、1つのファイルを直接実行しながら、文法やデザインパターンを学んできました。

しかし実際の開発現場では、コードは<span class="info">「プロジェクト」</span>という単位で管理され、<span class="info">外部の人が作った便利な部品（パッケージ）を組み合わせながら、アプリケーションを組み立てていきます。</span>

このレベルでは、その<span class="info">「プロジェクトを管理する」</span>ということが具体的に何を意味するのかを、実際に手を動かしながら学んでいきます。

まず、Node.jsのパッケージ管理ツールである`npm`を使って、新しいプロジェクトを作成し、パッケージをインストールし、実行する、という一連の流れを体験します。

次に、`npm`と並んでよく使われる`pnpm`にも触れ、それぞれのツールの違いを理解します。

最後に、プロジェクトごとに異なるNode.jsのバージョンを切り替える、実行環境のバージョン管理`nvm`についても扱います。

このレベルを通して、「動かすだけのコード」から、「チームで共有し、育てていくプロジェクト」へと、視点を一歩広げることを目指します。
